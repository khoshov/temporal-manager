# Temporal Manager

FastAPI веб-приложение с графическим интерфейсом для мониторинга и управления воркфлоу в Temporal.

## Возможности

- **Мониторинг воркфлоу**:
  - Просмотр всех запущенных и завершенных воркфлоу в реальном времени.
  - Фильтрация по статусам (`Running`, `Completed`, `Failed`, `Canceled`, `Terminated`, `TimedOut`).
  - Быстрый поиск по Workflow ID и названию типа воркфлоу.
  - Поддержка нативных Temporal Visibility Queries (SQL-подобный синтаксис).
  - Настраиваемое автообновление (каждые 5, 10, 30 секунд или вручную).
  - Подробная карточка информации о воркфлоу (Run ID, Task Queue, Start/Close Time, History Length).

- **Управление воркфлоу по кнопке**:
  - Быстрый запуск воркфлоу с автогенерацией уникальных ID (или указанием своего).
  - Пресет для `BaseWorkflow.run`.
  - Передача входных аргументов в формате JSON.
  - Опция автоматической отмены через N секунд (тестирование отмены).
  - Кнопки отмены (`Cancel`) и принудительного завершения (`Terminate`) активных воркфлоу.
  - Кнопка повторного запуска (клонирования параметров).

- **Настройка сервера и сертификатов в Web UI**:
  - Настройка Endpoint сервера (например, `localhost:7233` или `your-namespace.tmprl.cloud:7233`).
  - Указание Namespace (по умолчанию `default`).
  - Включение/отключение TLS / mTLS прямо переключателем.
  - Загрузка сертификатов (`cert.pem`, `key.pem`, `ca-chain.pem`) через UI или вставка PEM-текста.
  - Поддержка `verification_server_name` и `domain`.
  - Автоматическое сохранение конфигурации в `secrets/connection_config.json`.

## Быстрый старт

### 1. Установка зависимостей

```bash
# При использовании uv (быстро):
uv venv --python 3.12
uv pip install -r requirements.txt

# Или обычный pip:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
# Активируйте окружение и запустите uvicorn:
source .venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Откройте в браузере: **[http://localhost:8000](http://localhost:8000)**

## Настройка подключения в UI

1. Нажмите на бейдж статуса или иконку настроек в шапке приложения.
2. В открывшемся окне укажите:
   - **Temporal Host**: адрес кластера (например, `localhost:7233` или `mycluster.temporal.io:7233`).
   - **Namespace**: ваше пространство имён (по умолчанию `default`).
   - **Использовать TLS / mTLS**: переведите в активное состояние, если кластер требует сертификаты.
   - Загрузите `.pem` файлы или переключитесь на вкладку «Вставить текст сертификатов (PEM)» и вставьте содержимое `cert.pem`, `key.pem` и `ca-chain.pem`.
   - При необходимости укажите `Verification Server Name`.
3. Нажмите **«Сохранить и подключиться»**. Статус в шапке станет зелёным.

## Запуск демо-воркера (опционально)

Для проверки работы локально (если запущен локальный сервер `temporal server start-dev`):

```bash
python worker_demo.py
```

После этого в веб-интерфейсе нажмите **«Запустить воркфлоу»**, выберите пресет `BaseWorkflow.run` и нажмите **«Запустить»** — вы увидите статус `RUNNING`, а затем `COMPLETED`.
